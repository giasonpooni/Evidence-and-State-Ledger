# Internal industrial source review

`src/acquisition/industrial-review.ts` is a narrow client of the existing
`LocalEvidenceIntake`, content-addressed byte store and source policy evaluator.
It adds no new evidence store, admission authority, corpus release or endpoint.

The input is an operator-selected capture directory produced by GSC's bounded
NOAA station 9414290 / USGS 3DEP capture. Exact filenames, HTTPS hosts, paths,
query parameters, source IDs, content digests and clocks are checked before
retention. All five artifacts are preflighted. Bytes are captured through the
existing intake and reopened through its existing recomputation path. Partial
storage failure may leave retained bytes; it never produces a successful report.

The qualification policy permits only INTERNAL INGEST/DERIVE/RETRIEVE for
`industrial-source-qualification`. It is an operator declaration, not independent
legal confirmation. No public/customer export permission or canonical admission
is inferred from government-source availability. Explicit CLI permission is
required. Output creation is exclusive; existing outputs are never overwritten.

The report schema `payload.industrial-source-review.v1` binds the capture
manifest and the five retained acquisitions. It explicitly preserves
`canonicalAdmission: false`, `release: null`, `independentVerification: false`
and `sourceTruthClaimed: false`. Its digest verifies local serialization
integrity, not a digital signature or public release. The downstream GSC process
must be handed this report through trusted operator setup, not caller JSON.

The source supplies observation timestamps, not its publication timestamps.
HTTP response Date and local capture time must not be substituted for that
missing source clock. Existing admission/release and fixture-scoped projection
contracts are unchanged. GSV displays this material only as internal source
review; it must never label it an admitted release.

```sh
npx esbuild scripts/industrial-review.entry.ts --bundle --platform=node --format=esm --outfile=.stamp/industrial-review.mjs
node .stamp/industrial-review.mjs CAPTURE_DIR INTAKE_DIR NEW_OUTPUT.json --allow-internal-qualification
npx vitest run src/acquisition/industrial-review.test.ts src/data-os/local-intake.test.ts src/domain/admission.test.ts
```

Tests use generated bytes and real local-store operations. They do not claim
that their fixtures came from NOAA/USGS. The separate private end-to-end workflow
captures actual sources, re-decodes terrain, runs this intake, compiles with a
pinned public GSC checkout, and renders with a pinned public GSV checkout.
No private ESM source is copied into either public repository or viewer bundle.
